## How did I do this?
First, make sure that you have Git and VSCode installed, and that you have a GitHub account.
1. Create a folder in File Explorer, so that you can access it through VSCode
2. Open VSCode
3. Through Explorer (top left icon under VSC logo), open the folder you created
4. Create a README.md file
5. Write whatever shenanigans you want to write (ideally an intro of yourself or something similar)
6. Open the Source Control Panel and initialize a repository
7. Hover over the file and click "+" to stage changes
8. Write a commit message in the text box and click "Commit"
9. Click the "Publish Branch" button
10. Celebrate, you created your first repo!
